Teaching Pack

Groq PDF Prompt Workshop

This folder teaches prompt engineering with one searchable invoice PDF: sample_ocr.pdf. Every example uses the same Groq-based RAG pipeline. The only thing that changes is the prompt style.

What learners will see

  1. How a searchable PDF becomes model context.
  2. How chunking and retrieval narrow the prompt.
  3. How the same document answers differently under different instructions.
  4. How to write their own prompts with purpose, structure, and audience in mind.

How the Process Works

1. Read the PDF

The code reads text from sample_ocr.pdf. This version assumes OCR is already done, so the file is searchable.

2. Chunk the Text

The text is split into smaller overlapping chunks so retrieval stays focused instead of sending the whole document every time.

3. Retrieve Context

The question and each chunk are embedded with a local embedding model. The most similar chunk is selected.

4. Ask Groq

Groq receives the retrieved chunk plus your prompt. The quality of the final answer depends heavily on how clearly that prompt defines the job.

How to Create Your Own Prompt

Start with the task

Decide what you want. Do you want a summary, a table, a risk review, a JSON extraction, or a beginner-friendly explanation?

Name the audience

Say who the answer is for: a student, a procurement officer, a finance reviewer, or a customs team.

Ask for a format

Structured prompts are easier to evaluate. Ask for bullets, sections, tables, or JSON instead of leaving the format open.

Add boundaries

Tell the model to use only the provided context, mark uncertainty clearly, and separate facts from concerns.

Simple Prompt Formula

You are helping [audience].

Your task is to [goal].

Use only the provided context.

Return the answer as [format].

If something is unclear, say "uncertain from context".

Prompt Templates Learners Can Reuse

Basic

Simple Summary

What are the main findings in this document?
Structured

Headings Prompt

Summarize this invoice using these headings:
1. Seller
2. Buyer
3. Items and Prices
4. Total Amount
5. Payment Terms
6. Risks to Double-Check
Large Prompt

Analyst Prompt

You are a finance and operations analyst.
Use only the context.
Start with a short summary.
Then list key commercial facts.
Then add a section called Checks and Concerns.
One-Shot

Example-Led Prompt

Give the model one tiny invoice example first,
then ask it to answer the real invoice in the same style.
Extraction

JSON Prompt

Extract invoice_number, date, buyer, total_amount,
currency, country_of_origin, and payment_terms.
Return valid JSON only.
Teaching

Beginner Prompt

Explain this document to a beginner
who has never seen a proforma invoice before.
Use plain English and short paragraphs.

Best Teaching Sequence

Step 1

Run the basic version first so learners see the simplest possible prompt.

Step 2

Run the structured version next so they see how headings improve readability.

Step 3

Run the large-prompt version to show how stronger instructions shape analysis depth.

Step 4

Run the one-shot version last to show how examples can teach the model the answer style.

The key lesson is simple: same PDF, same model, same retrieval. Change the prompt, and you change the task.
